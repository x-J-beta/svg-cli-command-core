| F03 | front/back、addto 默认追加、带 index 插入、排序撤销 |

## 常见非法输入覆盖

| 编号 | 场景 |
|---|---|
| E01–E02 | 未初始化文档 |
| E03 | 未知命令 |
| E04–E09 | move 参数数量不对、目标不存在、NaN、Infinity、非数字 |
| E10–E16、E46–E47 | scale 缺参数/多参数、无目标、零或负倍率、非有限数；空容器也不能绕过校验 |
| E17–E21 | id 不可修改、属性不属于该图形、组无几何属性、负尺寸/描边宽度 |
| E22–E27、E44 | 重复 id、未知类型、负半径、创建参数缺失、in 目标无效、空 id |
| E28–E33 | 叶子作为容器、自包含、向子孙迁移、负数/小数/越界 index |
| E34–E35 | 同时分组祖先和子孙、重复成员 |
| E36–E38 | 解散根级组、解散叶子、删除不存在的对象 |
| E39–E42 | 非法画布尺寸、参数缺失、没有保存路径、show 无目标 |
| E43、E45 | 引号未闭合、无可重做命令 |

各非法命令同时核对错误信息和失败后的可见对象、属性、父关系、顺序、隐藏容器及画布状态。历史是否保留通过 F07 与 G10 的后续 redo 验证。

## move/scale 底层边界

| 编号 | 覆盖内容 |
|---|---|
| G01–G02 | 后续坐标或尺寸溢出时，首次属性写入都不能发生 |
| G03–G04 | 直接调用命令传入非有限数/非法倍率，包含空容器 |
| G05 | 大位移丢失浮点低位后，撤销仍精确恢复原值，并即时生成新的 redo 命令 |
| G06 | 极小正倍率下溢为 0 后，仍可精确撤销 |
| G07 | 空操作仍占一个撤销单元，新空操作也会清空 redo |
| G08 | 隐藏、未挂载及其他文档中的对象不能操作 |
| G09 | 导入 transform 保留，字号、文本和描边宽度不变，几何仍按局部坐标修改 |
| G10 | 数值溢出失败不清空已有 redo |

固定场景中的文件接口使用内存实现，以稳定控制缺文件/不可写等条件；XML 解析和序列化调用真实实现。真实文件系统保存、替换和读回仍由原有 editor.test.mjs 的集成测试覆盖。
